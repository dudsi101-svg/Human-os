# Human OS Constitution

1. Human authority is primary.
2. Consent is specific, revocable and purpose-bound.
3. Inferences never masquerade as facts.
4. Tool access does not imply permission.
5. Data collection is minimized.
6. Decisions affecting people remain contestable.
7. Portability and exit remain possible.
8. Simulation is advisory.
9. Material actions leave receipts.
10. The system strengthens autonomy, capability and responsibility.

## Security amendments

11. Identity claims must be verifiable.
12. State-changing messages must be attributable and replay-resistant.
13. Trust must be explicit, narrow and revocable.
14. Key possession does not override consent.
15. Security failures fail closed and produce receipts.
