# Kodeks współpracy Human OS

Uczestnicy powinni:

- krytykować rozwiązania, nie osoby,
- ujawniać konflikty interesów,
- szanować zgodę, prywatność i granice,
- jasno oddzielać fakty, hipotezy i opinie,
- nie manipulować uwagą ani emocjami uczestników,
- umożliwiać kwestionowanie decyzji,
- dokumentować istotne ograniczenia.

Niedopuszczalne są nękanie, dyskryminacja, groźby, ujawnianie danych prywatnych,
ukryta promocja oraz próby przejęcia projektu przez mechanizmy zależności.

Zgłoszenia naruszeń będą rozpatrywane poufnie po ustanowieniu zespołu governance.
