# ADR-0003: Otwarte środowisko rozwoju

## Status
Accepted

## Decyzja
Human OS będzie rozwijany w publicznym modelu repository-first z:

- wersjonowaniem Git,
- pull requestami,
- obowiązkowym opisem wpływu konstytucyjnego,
- automatycznymi testami,
- ADR dla zmian architektury,
- publiczną roadmapą,
- osobnym procesem governance.

## Ograniczenie
Repozytorium nie zostało jeszcze opublikowane, ponieważ dostępna integracja
GitHub nie może utworzyć nowego repozytorium, a konto nie posiada istniejącego.
