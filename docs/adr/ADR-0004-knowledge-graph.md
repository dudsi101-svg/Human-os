# ADR-0004: Knowledge Graph and Provenance

## Status
Accepted

## Decision
Human OS will represent knowledge, people, intents, actions, systems and flows as
typed nodes connected through explicit, confidence-bearing relations.

Every material knowledge claim may carry provenance describing:

- source type and reference,
- human author when known,
- observation time,
- confidence,
- verification status,
- derivation method,
- limitations.

## Constitutional rationale
The graph must make influence visible instead of hiding it. Provenance protects
human authorship, enables verification and reduces dependence on opaque inference.

## Limitation
Path confidence multiplication is a provisional reference model. It must not be
treated as an objective measure of truth.
